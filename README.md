# Windows Apps

Windows desktop applications, one folder each.

| App | What it is |
| --- | --- |
| [**Eve's Garden**](EvesGarden/) | A music player and downloader. Reads track and album details from Spotify, pulls audio from YouTube, tags it, and plays it back with a 10-band EQ, synced lyrics, 32 visualisers and Discord Rich Presence. |

Each folder is self-contained: its own README, dependencies and build steps.
